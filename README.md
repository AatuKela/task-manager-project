# Task Manager

## Overview

Task Manager is a simple browser-based task management application developed using HTML, CSS, and JavaScript.

The application allows users to manage daily tasks through a simple and intuitive interface.

## Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Filter tasks
- Save tasks using Local Storage

## Technologies

- HTML
- CSS
- JavaScript
- Local Storage
- GitHub

## Installation

1. Download the project files.
2. Open index.html in a web browser.
3. Start managing tasks.
